# Smart Trip Planner ✈️

A Python-based travel planning web application built using Streamlit and MySQL.

## Features
- Explore popular travel destinations
- Generate personalized travel itineraries
- Estimate trip budgets
- Store and manage trip details using MySQL
- View planned trips

## Technologies Used
- Python
- Streamlit
- MySQL
- Pandas
- Matplotlib

## How to Run

1. Clone the repository.
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Configure your MySQL database connection.
4. Run the application:
   ```bash
   python -m streamlit run app.py
   ```
